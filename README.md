# Adaptive-RecSys

사용자의 일시적인 행동에 대한 추천 모델의 민감성을 측정하고 개선하는 연구 프로젝트입니다.

## 첫 번째 연구 질문

기존 관심사와 무관한 클릭 한 번이 SASRec의 추천 결과에 얼마나 영향을 주는가?
민감성이 관찰된다면, 기존 추천 정확도를 유지하면서 그 영향을 줄일 수 있는가?

## 진행 순서

1. SASRec baseline 재현
2. 무관한 클릭 삽입·교체 실험
3. 관찰된 문제의 원인 분석 및 모델 개선
4. 정확도, 안정성, 관심사 변화 적응 성능 비교

## 개발 환경

- WSL 2 / Ubuntu 26.04
- Python 3.14 가상환경
- PyTorch: CPU 연산 확인 완료
- Intel Arc 140V GPU: XPU 사용 가능 여부 추후 확인
